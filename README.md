## Scope and reproducibility

This repository currently publishes the report rather than a runnable model implementation. Training code, an inference application, datasets, model weights, and an environment specification are not included, so there is no installation or execution command to follow here.

Consult the report for the project’s methodology and any reported results. Reproducing the experiments would additionally require the implementation, dependency versions, dataset provenance and splits, and a training recipe or checkpoint.
